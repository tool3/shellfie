# shellfie

Take a selfie of your shell.

```typescript
import shellfie from 'shellfie';

const svg = shellfie('\x1b[32m✓\x1b[0m All tests passed');
```

![macOS Terminal](examples/svgs/macos.svg)

## Why?

Because your terminal output deserves better than a blurry screenshot.

- **SVGs scale infinitely** — pixel-perfect at any size
- **Text is selectable** — copy code right from the image
- **Tiny files** — typically 2-10KB vs 100KB+ PNGs
- **Full ANSI support** — colors, styles, unicode, box drawing
- **Zero dependencies** — fast and lightweight

## Install

```bash
npm install shellfie
```

## Usage

```typescript
import shellfie from 'shellfie';

// capture any terminal output
const svg = shellfie(terminalOutput, {
  template: 'macos',
  title: 'npm test'
});
```

|-------|---------|---------|
| ![macos](examples/svgs/macos.svg) | ![windows](examples/svgs/windows.svg) | ![minimal](examples/svgs/minimal.svg) |

```typescript
shellfie(output, { template: 'macos' });   // default
shellfie(output, { template: 'windows' });
shellfie(output, { template: 'minimal' });
```

## Real Commands

Capture actual command output:

```typescript
import { execSync } from 'child_process';

const log = execSync('git log --oneline --graph --color=always').toString();
const svg = shellfie(log, { title: 'git log' });
```

![Git Log](examples/svgs/git-log.svg)

## Options

```typescript
shellfie(input, {
  template: 'macos',                          // 'macos' | 'windows' | 'minimal' | Template
  title: 'my-terminal',                       // window title
  watermark: 'Generated by shellfie',         // bottom-right text (supports ANSI)
  fontSize: 14,                               // font size in pixels
  lineHeight: 1.4,                            // line height multiplier
  padding: 16,                                // number | [v, h] | [top, right, bottom, left]
  width: 80,                                  // terminal columns (auto if not set)
  windowControls: true,                       // show window buttons
  fontFamily: "'SF Mono', Monaco, monospace", // font family
  theme: customTheme,                         // custom color theme
  customGlyphs: true,                         // native box drawing shapes
});
```

## Async with Font Embedding

For portable SVGs that look identical everywhere:

```typescript
import { shellfieAsync } from 'shellfie';

const svg = await shellfieAsync(input, { embedFont: true });
```

## Custom Themes

```typescript
import shellfie, { createTheme } from 'shellfie';

const theme = createTheme({
  name: 'ocean',
  background: '#0a2540',
  foreground: '#e6f1ff',
  red: '#ff6b6b',
  green: '#69db7c',
  // ... all 16 ANSI colors
});

shellfie(output, { theme });
```

## Works With Everything

### Chartscii

```typescript
import Chartscii from 'chartscii';

const chart = new Chartscii(data, { colorLabels: true });
const svg = shellfie(chart.create(), { title: 'Analytics' });
```

![Chartscii](examples/svgs/chartscii.svg)

### Any CLI Tool

```typescript
// git diff
shellfie(execSync('git diff --color=always').toString());

// test runners
shellfie(execSync('npm test 2>&1').toString());

// linters, formatters, anything with ANSI output
```

## Utilities

```typescript
import { parse, render, stripAnsi, getMaxWidth } from 'shellfie';

// parse without rendering
const lines = parse('\x1b[31mred\x1b[0m text');

// render parsed lines
const svg = render(lines, options);

// strip ANSI codes
stripAnsi('\x1b[31mred\x1b[0m'); // 'red'

// get terminal width
getMaxWidth(lines); // 80
```
